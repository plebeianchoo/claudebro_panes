# Deck: act on any Claude from one overview (tablet-first)

Date: 2026-10-16 · Repo: `claudebro_panes` (submodule of `~/claudebro`) · Status: approved design, not started

## Goal

Jeremy runs 2–3 Claudes (one tmux window each: Claude on top, `commands` shell below) and reaches
them from **Termius on an Oppo Pad Mini (Android, on-screen keyboard)**. Today `Ctrl-b T` / `Ctrl-b C`
show who needs him, but answering means leaving the overview. The deck fixes that: one window with the
**real** focused Claude and its real shell, plus live mirror strips of the others; **tap a strip to swap
it in**. It adapts to the on-screen keyboard shrinking the screen.

```
full (≥ threshold rows)                         compact (keyboard up, < threshold rows)
┌─ ◆ claude session (real, focused) ──────────┐  ┌─ ◆ claude session (real) ──────────────────┐
│                                             │  │ Claude gets every row but two              │
│ Claude Code, ~75% of the height             │  │                                            │
├─ ▸ commands (real) ─┬─ UwU ○ ─────┬─ OwO- ● ─┤  ├─ ▸ commands ─┬─ UwU ○ ──────┬─ OwO- ● ! ───┤
│ $ npm run dev       │ Done.       │ ✻ Think… │  │ ready :3000  │ >            │ ✻ Thinking…  │
└─────────────────────┴─────────────┴──────────┘  └──────────────┴──────────────┴──────────────┘
status bar: … [ + ] [ git ] [ next ] …           tap a strip = swap it into focus; [ next ] = next waiting Claude
```

## Screen arithmetic (why the design looks like this)

Oppo Pad Mini: 8.8", 2480×1504, ≈330 ppi. Measured in Task 0 (2026-10-16, Termius client from
192.168.86.29). The 182×50 client seen earlier is a different device (192.168.86.30), not the Pad.

| Orientation | Keyboard | Size | Note |
|---|---|---|---|
| landscape | down | 165×50 (inferred) | not captured; 15 px cells across 2480 px → ~30 px rows → 1504/30 ≈ 50 |
| landscape | up | **165×11** (measured) | keyboard takes ~78% of the rows; compact mode leaves Claude ~9 rows: read-only in practice |
| portrait | down | 109×50 (measured) | |
| portrait | up | **109×29** (measured) | **the typing pose**: full mode still fits (7-row bottom, ~21 rows for Claude) |

Font: one pinch smaller is the readable limit (~0.9 mm per character); smaller buys little. The real fix
is portrait when typing; compact mode only keeps landscape-with-keyboard glanceable and tappable.

## Decisions

| # | Decision | Why |
|---|---|---|
| D1 | Deck **replaces** the stacked-mirror `team` window on `Ctrl-b C` | Same purpose, one key to remember. `team-window.sh` is renamed (`git mv`) to `deck.sh`, not deleted |
| D2 | Focused Claude **and its shell** are the *real* panes, moved in with `swap-pane -d` against mirror placeholders | Full typing in place; pane ids never change, so `bell.sh`, `@role`, hooks keep working |
| D3 | Shell sits in the bottom row beside the strips, not on its own row | Claude keeps ~75% of the height (Jeremy's pick) |
| D4 | Mirrors are retargetable: target comes from the pane option `@cb_mirror_of`, label goes to the pane title | Swaps only retarget strips; nothing is rebuilt |
| D5 | Touch first: **tap a strip** swaps (mouse binding, only on mirror panes); status-bar **`next`** button = next waiting Claude; `Ctrl-b Space` (deck only) is the same for a hardware keyboard | Ctrl-b chords are awkward on the Termius on-screen keyboard |
| D6 | `next` button is the ASCII word, not `⏭` | U+23ED has ambiguous width; tmux status and Termius may disagree and misplace click ranges |
| D7 | Height-adaptive layout via a global `client-resized` hook → `deck.sh layout`: bottom row = max(6, 25%) rows when height ≥ threshold, else **1 row** | On-screen keyboard cuts landscape from ~50 to 11 rows; borders keep `UwU ○ !` visible and tappable |
| D8 | Threshold = **26 rows** (Task 0: (11 + 29) / 2 = 20, clamped to 26–40) | Portrait-keyboard-up (29) stays full; landscape-keyboard-up (11) goes compact |
| D9 | `Ctrl-b &` in the deck = `deck.sh close` (swap everything home, then remove the deck); `close` is idempotent and also repairs | Plain `kill-window` on a deck would kill a real Claude |
| D10 | Fix pane lookup: `USAGE.md` and the `walking-through-in-bottom-pane` skill pick the **`@role=commands` pane in Claude's own window** | Today USAGE says `list-panes -a` (ambiguous with 3 windows); the skill's "lowest pane" would pick a **strip** in the deck, and an Enter there triggers a swap |

**Left out:** auto-swap when a Claude finishes (would steal the screen mid-typing); more than ~4 Claudes
(strips get narrow; documented limit); a deck per session (one deck lists Claudes from all sessions, like
`team-window.sh` did); portrait-specific layout (the same layout works, cells just get narrower).

## Shared test harness (used by Tasks 1–4)

All tests run on a throwaway tmux server so Jeremy's live session is never touched. Paste once per shell:

```sh
cd ~/claudebro/claudebro_panes
S=/tmp/claude-1000/decktest; mkdir -p "$S/bin"
cp /bin/sleep "$S/bin/claude"          # a process whose name really is "claude"
T() { tmux -L decktest "$@"; }
T kill-server 2>/dev/null
T -f /dev/null new-session -d -s main -x 182 -y 50 -n a
T set -g mouse on; T source-file tmux/claudebro.conf
for w in a b c; do
  [ "$w" = a ] || T new-window -d -t main: -n "$w"
  top=$(T display -p -t "main:$w" '#{pane_id}')
  T send-keys -t "$top" "exec $S/bin/claude infinity" Enter
  bot=$(T split-window -d -v -t "$top" -P -F '#{pane_id}')
  T set -p -t "$top" @role claude; T set -p -t "$bot" @role commands
done
sleep 1; T list-panes -a -F '#{pane_id} #{window_name} #{@role} #{pane_current_command}'
```

Expected: 6 lines; windows a/b/c each with one `claude claude` and one `commands bash`.
Make `b` idle with `T select-pane -t <b's claude id> -T '✳ idle'`. Run scripts inside the test server with
`T run-shell 'CLAUDEBRO_DECK_DETACH=1 ~/claudebro/claudebro_panes/shell/deck.sh <cmd>'` (no client is
attached, so `DETACH=1` skips `switch-client` / `select-window` calls). Tear down: `T kill-server`.

### Task 1: Retargetable mirror (`shell/team-mirror.sh`)

Files: `shell/team-mirror.sh`

Steps:
1. Target = `$(tmux show -pqv -t "$TMUX_PANE" @cb_mirror_of)`, falling back to `$1`. Re-read it every loop.
2. Each loop, also compute a label and set it as this pane's title (`select-pane -t "$TMUX_PANE" -T`), only
   when it changed:
   - target is in a window with `@cb_deck` set (and this mirror is not) → `◆ in deck: tap to go there`;
   - otherwise → `<window_name> ○|●[ !]`. `○` if the target's title starts with `✳`, else `●`;
     ` !` if `#{window_bell_flag}` of the target's window is 1.
3. Enter (and taps, Task 4) no longer `switch-client` here directly: Enter runs `"$here/deck.sh" tap "$TMUX_PANE"`
   (deck.sh decides: swap or go to the deck).
4. Keep: no cursor, no wrap, 1 s refresh, `(pane %N is gone)` when the target vanished.

Verify (harness): `T new-window -d -n m "$PWD/shell/team-mirror.sh <a's claude id>"`, wait 2 s, then
`T list-panes -t main:m -F '#{pane_title}'` → `a ●`. Then
`T set -p -t main:m @cb_mirror_of <b's claude id>`, wait 2 s → title becomes `b ○`.
Commit: `Mirror: retarget via @cb_mirror_of, show window/state/bell in the title`.

### Task 2: `deck.sh` open / focus / close / tap

Files: `git mv shell/team-window.sh shell/deck.sh`, then rewrite.

Interface (`deck.sh <cmd>`); env overrides: `CLAUDEBRO_DECK_NAME` (default `deck`),
`CLAUDEBRO_DECK_SESSION` (default current), `CLAUDEBRO_DECK_DETACH=1`.

- **Claude list:** every pane with `pane_current_command == claude`, or `@role == claude`, outside deck
  windows, in session/window order, plus any real pane currently in the deck. Its shell = the `@role=commands`
  pane in the same window (none → the shell slot shows `(no shell)`).
- **open:** if a window with `@cb_deck` exists in the session, select it and exit. Else create window
  `deck` (`set -w @cb_deck 1`): focus placeholder (mirror, `@cb_slot focus`), split `-v` for the bottom row:
  shell placeholder (`@cb_slot shell`), then `split -h` one strip per other Claude (`@cb_slot strip`),
  equal widths. Then `focus <first waiting Claude, else first>`, then `layout`.
- **focus <claude_pane>:** (a) if a real Claude is in the deck, swap it and its shell home
  (`swap-pane -d -s <real> -t <its @cb_deck_twin>`, unset `@cb_deck_twin`). (b) `swap-pane -d` the new Claude
  with the focus placeholder and its shell with the shell placeholder; set `@cb_deck_twin` on each real pane
  and `@cb_mirror_of` on each placeholder (now in the home window, it mirrors the real pane → label
  "in deck"). (c) Retarget strips to the other Claudes; if the count changed, kill and recreate strip panes
  (mirror panes only). (d) Unless DETACH: `select-window` the home window then the deck in one
  `run-shell` to clear its bell flag; select the focus pane.
- **tap <mirror_pane>:** mirror in the deck (`@cb_slot strip`) → `focus <its @cb_mirror_of>`;
  a placeholder in a home window → select the deck window.
- **close:** for every pane in every session with `@cb_deck_twin`: swap back and unset. Kill deck windows
  (only mirrors remain in them). Kill mirror placeholders left in home windows whose target is gone.
  Safe to run twice; with no deck it does nothing and exits 0.

Verify (harness):
- `T run-shell '… deck.sh open'`, then
  `T list-panes -t main:deck -F '#{pane_id} #{@role} #{@cb_slot} #{pane_current_command}'`
  → real `claude` (b, the idle one) + real `commands` + 2 strips. Panes in `main:b` are now 2 mirrors.
- `T run-shell '… deck.sh focus <a claude id>'` → deck holds a's panes; b's real panes are back in `main:b`
  (`T list-panes -t main:b -F '#{@role}'` → `claude`, `commands`).
- `T run-shell '… deck.sh close'` twice → no `deck` window; `T list-panes -a -F '#{window_name} #{@role}'`
  is identical to the harness's starting output; second run exits 0.
- Pane ids of all six real panes are unchanged throughout (compare with the harness output).

Commit: `Deck: swap the real Claude and shell into a focus slot (replaces team window)`.

```json:metadata
{"files": ["shell/deck.sh", "shell/team-window.sh"], "acceptanceCriteria": ["open/focus/close round-trip restores the original layout", "pane ids unchanged", "close idempotent"], "modelTier": "frontier"}
```

### Task 3: `deck.sh next` and `layout`

Files: `shell/deck.sh`

- **next:** from the Claude list, starting after the focused one and wrapping, pick the first that is
  waiting (title starts with `✳` or its home window's bell flag is set); none waiting → simply the next one.
  Then `focus` it.
- **layout:** for every deck window: `h = window_height`. Bottom rows = `max(6, h*25/100)` if
  `h >= THRESHOLD` (26, from Task 0), else `1`. Apply with `resize-pane -t <shell slot or its real pane> -y rows`,
  then equalise the bottom row's widths. No deck → exit 0 silently (it runs on every resize).

Verify (harness):
- `T resize-window -t main:deck -x 182 -y 50; T run-shell '… deck.sh layout'` →
  the bottom-row pane's `#{pane_height}` is 12; the focus pane is ~35.
- `T resize-window -t main:deck -x 182 -y 25; T run-shell '… deck.sh layout'` → bottom row height 1.
- With b idle and a focused: `deck.sh next` → b is focused; again → c (none waiting) → wraps.

Commit: `Deck: next-waiting and height-adaptive layout`.

### Task 4: tmux wiring (keys, tap, `next` button, resize hook)

Files: `tmux/claudebro.conf`, `tmux/nord.conf`

1. `bind C run-shell "'#{@claudebro}/shell/deck.sh' open"`
2. `bind & if -F '#{@cb_deck}' { run-shell "'#{@claudebro}/shell/deck.sh' close" } { confirm-before -p "kill-window #W? (y/n)" kill-window }`
3. `bind Space if -F '#{@cb_deck}' { run-shell "'#{@claudebro}/shell/deck.sh' next" } { next-layout }`
4. Tap on a mirror:
   `bind -n MouseDown1Pane if -F -t = '#{@cb_mirror_of}' { run-shell -t = "'#{@claudebro}/shell/deck.sh' tap '#{pane_id}'" } { select-pane -t = ; send-keys -M }`

   the `MouseDown1Status` chain that runs `deck.sh open` if no deck exists, else `deck.sh next`.
6. `set-hook -g client-resized "run-shell \"'#{@claudebro}/shell/deck.sh' layout\""`

## Risks

- **Killing the deck other than with `Ctrl-b &`** (e.g. `kill-window` from the command prompt, `Ctrl-b x` on
  the focus pane after confirming) kills real panes: tmux has no veto hook. Mitigation: `&` rebound,
  `deck.sh close` repairs; documented.
- **`if -F -t =` in a mouse binding** must resolve `@cb_mirror_of` against the tapped pane; verify in Task 7
  step 2. If it doesn't, fall back to `run-shell -t = "deck.sh tap '#{pane_id}'"` unconditionally, with
  `tap` replaying `select-pane` for non-mirror panes.
- **Several clients at different sizes** (laptop + tablet): `window-size latest` makes the deck follow the
  last active client; layout reruns on each resize. Acceptable.
- **Glyphs in the window tabs** move: while a Claude is in the deck, its home window shows no `●/○` and the
  deck shows one. Strip labels carry the state instead.
- **Termius on-screen keyboard estimates** may be off; Task 0 replaces them before any threshold is coded.
- Claude Code redraws on every resize (swap = resize); expect a one-frame flicker.
